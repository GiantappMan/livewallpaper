# 本地库「桌面模式」：自由拖放布局 + 拖入子文件夹 + 打开子文件夹

## 目标交互（对齐 Windows 桌面）
- 本地库子文件夹层级改为**桌面画布**：壁纸和子文件夹以约 100px 小图标磁贴（封面缩略图 + 名称）混排，位置按隐形网格槽位 (列, 行) 摆放，可拖到任意空位，**位置持久化**（按文件夹记忆）。
- **单击选中**（高亮，点空白取消），**双击**应用壁纸 / 进入文件夹；逐屏应用改用页头已有「应用目标」选择器 + 右键菜单。
- 拖拽（自绘指针拖拽，替代现有 HTML5 DnD）：
  - 拖到**文件夹磁贴**上高亮，松手 → 移入该文件夹（壁纸走现有 `move_wallpaper`；**文件夹移入文件夹走新增后端命令**）；
  - 拖到**面包屑段** → 移动到上级目录（保留现有能力）；
  - 拖到**空白槽位** → 换位置；拖到已占用槽位 → 与目标**交换位置**（Windows 行为）；
  - 松手后防抖持久化布局。
- 空白处右键菜单加「自动整理」（清空当前文件夹的自定义布局，恢复按名称/类型自动排列）；页头排序下拉仍决定自动排列顺序。
- 根层级（库根目录列表）保持自动排列，不做自由摆放（通常只有一两个根，无意义）。
- 搜索时忽略位置，沿用现有自动网格全局搜索结果。
- 旧版宿主（SDK 无新接口）：一切可见但位置不持久化；文件夹拖入文件夹 toast 提示升级（复用 `local.needUpdate` 模式）。
- OS 文件拖入导入（现有 HTML5 drop）不受影响。不做：多选拖拽、框选、文件夹重命名。

## 一、后端（Rust）

**`src-tauri/crates/wallpaper-core/src/library.rs`** 新增：
- `#[derive(Serialize, Deserialize)] pub struct LayoutSlot { pub c: u32, pub r: u32 }`
- `pub fn get_layout(dir: &Path) -> BTreeMap<String, LayoutSlot>`：读 `<dir>/.metadata/layout.json`，不存在返回空表（布局按「条目名 → 槽位」存，名字在目录内唯一）。
- `pub fn save_layout(roots, dir, layout)`：校验 dir 在库内（`locate_root`）、必要时创建 `.metadata`、原子写（`.tmp` + rename，仿 ConfigStore）。
- `pub fn move_folder(roots, src, target_parent) -> Result<PathBuf>`：校验 src 是库内子目录（depth ≥ 1，根不可移）、目标在库内、不是自身/自身子孙（`norm_path_str` 前缀）、`dst_depth + 1 <= MAX_FOLDER_DEPTH`、目标无同名；`fs::rename` 优先，失败（跨盘）回退递归复制 + 删除。文件夹自己的布局在其内部 `.metadata` 里，随目录自动带走。

**`src-tauri/src/commands.rs`** 新增命令：
- `get_folder_layout(app, dir: String) -> Result<BTreeMap<String, LayoutSlot>>`
- `save_folder_layout(app, dir: String, layout: BTreeMap<String, LayoutSlot>) -> Result<bool>`（**不**触发 notify_change，避免反复全量刷新）
- `move_folder(app, source: String, target_dir: String) -> Result<String>`：先停掉正在播放且路径位于 source 之下的壁纸（仿 `move_wallpaper` 的匹配逻辑，前缀匹配），移动后 `save_snapshot` + `notify_change`，返回新路径。

**`src-tauri/src/lib.rs`**：invoke_handler 注册这三个命令。

## 三、皮肤 skin-fluent

**`assets/core.js`**：
- `SC.getFolderLayout(dir)` / `SC.saveFolderLayout(dir, layout)`：特性检测 `typeof client.api.getFolderLayout !== "function"` → 返回 `{}` / 静默跳过；demo 模式内存 mock。
- `SC.moveFolder(src, target)`：接口缺失 → toast `local.needUpdate` 返回 null；demo mock。
- i18n 新增键（中英）：`local.rearrange`（自动整理 / Auto arrange）。

**`assets/app.js` `renderLocal()` 重构**（核心工作量）：
1. 删除 `foldersEl` + `grid` 双区，改为单一 `.loc-canvas`（relative 容器）；`localDir` 为空（根层级）或搜索态时沿用现有流式网格渲染分支。
2. 磁贴 `tileOf()`：紧凑样式（封面缩略图 + 名称；播放中徽标；文件夹含递归计数）；hover 显示设置/删除迷你按钮；右键菜单沿用现有项（应用/移动到/设置/定位/删除），文件夹磁贴加「打开」。
3. 布局计算：`columns = floor(画布宽 / 单元格宽)`；每项位置 = 布局表[name]，无记录者按流式顺序（先文件夹后壁纸，按当前排序）找第一个空槽，**只把用户显式拖动过的位置写入布局表**；窗口 resize 监听重算列数并重排（不重拉数据）。
4. 指针拖拽（pointerdown → 4px 阈值判定拖拽）：半透明 ghost 跟随光标，`elementFromPoint` 命中检测文件夹磁贴/面包屑段加 `is-over` 高亮，松手提交（移入/换位/交换）；与磁贴单击选中、双击动作通过阈值共存；内部指针拖拽与 OS 文件导入 drop 互不干扰。
5. 落盘：拖动提交后更新内存布局表 + `SC.saveFolderLayout(localDir, table)`（防抖 ~400ms）；移出条目时从表中删除其键。
6. 「自动整理」：空白右键菜单项 → 清空当前目录布局表并持久化、重排；旧版宿主上仅内存生效。
7. 清理旧 HTML5 拖拽代码（`dragSrc`、`attachDrop` 在本地库的使用），保留 OS 文件导入 drop。

**`assets/style.css`**：新增 `.loc-canvas`（relative 画布）、`.loc-tile`（图标磁贴：缩略图/名称/选中 `is-selected`/拖拽中 `is-dragging`/hover 操作钮）、`.loc-ghost`（拖拽幻影）、`.loc-over`（文件夹高亮）、面包屑段投放高亮样式；`.loc-folders/.loc-grid` 保留给根层级/搜索态分支。
