# 皮肤系统

皮肤 = 一个**完全自定义的界面包**：任意技术栈（纯 HTML / Vue / React / Svelte…）
构建出的静态前端，放入皮肤目录即可在 设置 → 外观 → 皮肤 中一键应用。
`app` 型皮肤完整替换主窗口界面；`style` 型皮肤只注入一份 CSS 覆盖默认皮肤外观。

## 目录与清单

皮肤安装位置：`%LOCALAPPDATA%/LiveWallpaper4/skins/<id>/`

```
skins/
└─ my-skin/
   ├─ skin.json        # 清单（必需）
   ├─ index.html       # 入口（app 型）
   └─ ...任意静态资源（js/css/图片/字体…）
```

`skin.json`：

```json
{
  "id": "my-skin",
  "name": "我的皮肤",
  "version": "1.0.0",
  "author": "you",
  "description": "示例皮肤",
  "type": "app",          // app = 完整界面 | style = 仅 CSS 覆盖
  "entry": "index.html",  // app 型为 HTML 入口；style 型为 CSS 文件
  "compat": 4             // 清单兼容版本（应用大版本），当前必须为 4
}
```

规则：

- `id` 仅允许字母数字与 `-_.`（不得以 `.` 开头），且不能为 `default`。
- 清单非法、`compat` 不符、入口文件缺失 → 设置页标记为不可用；
  已应用的皮肤失效时主窗口**自动回退默认皮肤**，永不白屏。
- `style` 型皮肤在默认皮肤每个页面注入
  `<link rel="stylesheet" href="…/<entry>">`，适合纯配色 / 圆角 / 密度魔改。
- **资源引用必须用页面相对路径**（`src="app.js"`，不要带前导 `/`）：
  皮肤页面位于 `http://skin.localhost/<id>/index.html`，根相对路径会丢掉
  `<id>` 段而 404。唯一例外是 SDK：`/_sdk/client.js` 是协议根保留路径，
  必须带前导 `/`。

## 加载机制（Rust 侧 `src-tauri/src/skin.rs`）

- 主窗口 URL 由 `Appearance.skin` 配置决定：
  - `default` → 应用内置前端（`index.html`）；
  - app 型 → `http://skin.localhost/<id>/<entry>`（自定义协议，形态与
    `http://media.localhost` 一致）；
  - style 型 → 内置前端 + 初始化脚本注入 `<link>`。
- `skin://`（即 `http://skin.localhost`）协议只服务皮肤目录内的静态文件，
  逐段拒绝 `..`，并提供特殊路径 `/_sdk/client.js`（内置客户端 SDK）。
- 切换皮肤 = 更新 `Appearance.skin` → 后端让主窗口加载新目标（`recreate_main_window`）：
  app 型 / 默认皮肤之间直接 `navigate` 切换（同一个 webview 跳转新 URL，
  不销毁窗口——销毁重建在 Windows 上会连带事件循环崩溃）；style 型需要
  建窗时注入 init script，走兜底的销毁重建（延迟线程执行）。

## 客户端契约（皮肤能做什么）

皮肤运行在主窗口里，与内置 UI **同权**：

- **命令**：全部功能性 Tauri command（`invoke`）：`get_wallpapers`、
  `show_wallpaper`、`pause_wallpaper`、`resume_wallpaper`、`stop_wallpaper`、
  `play_next_in_playlist` / `play_prev_in_playlist`、`set_volume`、
  `get_playing_status`、`get_wallpaper_time`、`set_progress`、`get_config` /
  `set_config`、`download_wallpaper`、`get_download_history`、`get_mpv_status`、
  `get_screen_coverage`（实时每屏遮挡覆盖率）…
- **事件**（`listen`）：`playing-status-changed`（引擎每秒 tick 有变化时广播）、
  `download-status-changed`、`appearance-changed`、`refresh-page`、
  `navigate`、`system-theme-changed`、`mpv-download-event`、`hub-session-changed`、
  `skins-changed`（皮肤目录有增删 / 文件变化时广播，设置页据此刷新皮肤列表）。
- **SDK**：`<script src="/_sdk/client.js"></script>` 后获得全局
  `window.WallpaperClient`：

  ```js
  const { api, shell, types, on } = window.WallpaperClient;
  const res = await api.getWallpapers();   // ApiResult<T>: { error, data }
  await api.showWallpaper(res.data[0]);
  on("playing-status-changed", () => refresh());
  ```

  源码：`src/giantapp-wallpaper-ui/src/client-sdk/`（包装 `lib/client/api.ts`
  等 React 无关模块）；产物 `src-tauri/src/generated/client-sdk.js` 随源码入库，
  `bun run build:sdk` 重新生成。
- **媒体地址**：壁纸封面 / 文件经 `http://media.localhost/...`（`fileUrl` /
  `coverUrl` 字段）直接引用。
- **多窗口**：社区 Hub、OAuth 登录、壁纸播放器窗口由后端托管，皮肤无需（也无法）自建。
- **启动屏收尾**：app 型皮肤页面**加载完成后必须调用一次
  `shell.hideLoading()`**（`WallpaperClient.shell.hideLoading()`，幂等）——它负责
  关闭启动屏并显示主窗口。内置默认皮肤在启动引导完成后自动调用；皮肤漏调时，
  后端在主窗口页面加载完成后约 5 秒兜底关闭启动屏并显示主窗口
  （`finish_loading`，遵循"启动时隐藏主窗口"配置）。

## 安全与信任

皮肤与内置 UI 同权调用应用命令，等同于本机程序权限。请只安装可信来源的皮肤
（与 exe 型壁纸同级的信任模型）。

## 示例皮肤

- [`examples/skin-minimal/`](../examples/skin-minimal/)：单 HTML + SDK 的最小骨架，
  适合了解契约与起步。
- [`examples/skin-dev/`](../examples/skin-dev/)：**Dev 开发皮肤**（功能全集参考实现）。
  覆盖默认皮肤全部功能（壁纸库 / 播放控制 / 下载 / Hub / 设置 / 关于），额外提供
  事件流面板、原始 JSON 配置编辑器、运行环境自检与**遮挡检测可视化**
  （每屏遮挡状态 + 播放器实际响应的实时面板）。采用**面板注册表架构**——
  加新功能只需在 `panels/` 下新增一个 JS 文件并调用
  `DevSkin.register({ id, title, render })`，再在 `index.html` 加一行 `<script>`；
  共享工具（分块上传 / 播放列表创建 / 3x3 封面 / toast / 状态缓存）都在
  `core.js` 的 `DevSkin` 命名空间。二选一复制到 `skins/` 目录即可使用。

## 热更新开发（改完保存，应用自动刷新）

应用内置皮肤目录监听（`src-tauri/src/skin_watch.rs`）：`skins/` 下任何文件变化，

- 变化涉及**当前生效皮肤** → 广播 `refresh-page`，前端 / 皮肤 SDK 内置监听并整页
  刷新（`skin://` 协议每次请求实时读盘且 no-cache，刷新即最新内容）；
- 任何变化 → 广播 `skins-changed`，设置页自动刷新皮肤列表（新放入的皮肤即时出现）。

开发仓库里的皮肤无需来回复制：用联接脚本把皮肤源码目录挂进 `skins/`（一次性）：

```bash
scripts/link-skin.sh examples/skin-dev
# 即 skins/dev -> 仓库 examples/skin-dev（Windows 用 junction，无需管理员权限）
```

启动应用并在 设置 → 外观 → 皮肤 应用该皮肤后，编辑器里改皮肤文件保存，
窗口约半秒内自动刷新，与改普通前端代码体验一致。

边界说明：

- 修改 `skin.json` 的 `type` / `entry`（影响主窗口加载目标的字段）后，
  需在设置页**重新应用一次皮肤**（窗口 URL 是建窗时解析的）。
- 默认皮肤（`default`）是内置界面，不经 `skins/` 目录，无热更新概念；
  其前端改动走 `bun dev` 的 vite 热更新。
