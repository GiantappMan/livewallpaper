- 关于页全新设计：品牌卡片头部，展示主版本号

- 前端框架升级 Next.js 15 + React 19，清除全部依赖安全告警

### 修复

- 社区详情弹窗补齐窗口按钮，地址栏重做为浏览器工具条样式

## v3.1.0 发布日期：2026.10.14

### 功能

- 应用内更新检测：启动自动检查并下载，提示一键安装；支持正式版/预览版双通道，可在设置中配置更新地址（微软商店版走商店更新）
- 全新自绘标题栏（拖拽 + 窗口控制）
- 全新前端界面（Next.js 重写），打包链路同步迁移
- 仅支持 64 位系统
- 客户端安全加固：外部链接与进程调用统一校验
