# 开发

## 本地开发流程

- 一键启动调试（需 [bun](https://bun.sh)，对标 4.x）
  - `bun dev`：前端 dev server(:3000) + 自动补 mpv + 构建 Debug 客户端并启动（界面走 localhost:3000）
  - `bun dev --web`：只起前端；`bun dev --app`：只构建并启动客户端

- 启动[前端项目](../src/giantapp-wallpaper-ui-3_0/)
  - pnpm i（或 bun install）
  - pnpm dev

- mpv播放器（缺失时自动下载，也可手动放）
  - 自动：`powershell -ExecutionPolicy Bypass -File src/build/download-mpv.ps1`（打包时 compile.ps1 也会自动执行；从 shinchiro/mpv-winbuild-cmake 最新 release 下载，`-Force` 强制重下，`-PreferV3` 选 AVX2 变体）
  - 手动：从 <https://mpv.io/> 下载，把 7z 内容解压到[player目录](../src/giantapp-wallpaper-client/WallpaperCore/Assets/Players/Mpv/)下  
- vs2022 运行[客户端](../src/giantapp-wallpaper-client/)

## 编写规范

- 每个文件尽量只做单一可靠的事情，做好以后就不要频繁修改。有一个简单的标准可以评判：假如5年后的你来看刚写的这部分代码，是否会觉得麻烦，摸不着头脑，如果是就简化它。
- 接口定义应该简单，不需要包罗万象，只处理程序需要的场景
