Dev 开发皮肤 `examples/skin-dev/`（本文档各节均标注对应源码位置）。

## 0. 使用方式与维护约定

### 0.1 使用方式

- 做新皮肤时从 §1 开始逐节走查，`- [ ]` 项即一条可核对的需求；
  标 **[P0]** 的不做皮肤等于不可用，标 **[P1]** 的构成完整体验，标 **[P2]** 的可选。
- 每节末尾标注了默认 UI 的实现文件，拿不准语义时直接读源码。

### 0.2 维护约定（强制）

1. **新增 / 修改任何 UI 功能**（默认 UI 或 SDK），合入前同步更新本文档对应章节；
   新命令 / 新事件 / 新配置项必须同步 §10–§12 速查表。
2. 每次更新在 §14 追加一行（日期 + 变更摘要 + 关联提交）。
3. 需求删除或行为变更时直接改对应条目，不要只加注释。
4. 词典文案（`src/giantapp-wallpaper-ui/src/dictionaries/*.json`）新增 key 时，
   检查 §3.4 多语言需求是否需要同步说明。

## 1. 硬性契约（不做会白屏 / 404）

来源：`docs/3.皮肤系统.md`、`examples/skin-minimal/`。

- [ ] **[P0]** `skin.json` 清单齐全：`id`（字母数字与 `-_.`，不以 `.` 开头，≠ `default`）、
  `name`、`version`、`author`、`description`、`type`（`app` | `style`）、`entry`、`compat: 4`。
  任一校验失败会被设置页标记不可用；已应用的皮肤失效时主窗口自动回退默认皮肤。
- [ ] **[P0]** 引入 SDK：`<script src="/_sdk/client.js"></script>`。
  这是**唯一**允许带前导 `/` 的路径；其余资源一律页面相对路径
  （`src="app.js"`，不带前导 `/`），否则丢 `<id>` 段 404。
- [ ] **[P0]** 页面加载完成后调用一次 `shell.hideLoading()`（幂等）——关闭启动屏并
  显示主窗口。漏调时后端约 5 秒兜底，但期间用户面对启动屏。
- [ ] **[P0]** 媒体资源直接引用 `fileUrl` / `coverUrl` 字段（`http://media.localhost/...`），
  不要自行拼本地路径。
- [ ] **[P0]** 不拦截 `refresh-page` 事件（SDK 已内置整页 reload；皮肤文件热更新依赖它）。
  需按来源区分处理时，可在引入 SDK 前设 `WallpaperClientConfig.skipAutoRefresh = true`
  接管：`payload.reason == "wallpaper-config"`（壁纸配置/库数据变化）建议原地软刷新，
  其余来源仍整页 reload——见 skin-fluent 的 `core.js`。
- [ ] **[P1]** 浏览器直开（无 Tauri 环境）时优雅降级：所有 api 调用返回
  `{error:"no client"}`，页面给出引导提示而非报错白屏（参考 skin-dev 的 SDK 未加载横幅）。

## 2. 需求分级

| 级别 | 含义 | 范围 |
|---|---|---|
| **P0** | 不做则皮肤不可用 / 用户可感知明显残缺 | §1 契约、壁纸列表与应用、播放控制、状态刷新 |
| **P1** | 默认皮肤的完整体验 | 创建/编辑、下载、Hub、设置三页、关于、标题栏导航 |
| **P2** | 增强 / 运营性功能，可按皮肤定位取舍 | 评分弹窗、遮挡可视化、播放列表成员浏览等 |

## 3. 全局框架

实现：`src/giantapp-wallpaper-ui/src/App.tsx`、`components/{title-bar,side-menu,providers,theme-*}`。

### 3.1 自绘标题栏 **[P1]**

- [ ] 窗口无边框，标题栏需自绘：整条可拖拽（`data-tauri-drag-region` 或 `win.startDragging()`），
  双击空白切换最大化；内容区高度扣除标题栏（默认用 `--app-titlebar-h: 3rem` 约定）。
- [ ] 左侧：logo + 产品名 + 版本号（`api.getVersion()`）。
- [ ] 右侧三个窗口键：最小化（`win.minimize()`）、最大化/还原（`win.toggleMaximize()`，
  监听 `tauri://resize` 同步图标态）、关闭（`win.close()` → 后端转为**隐藏到托盘**）。
- [ ] 真正退出是 `api.exitApp()`（托盘菜单有此项；按 `Wallpaper.keepWallpaper` 决定是否清理桌面）。

### 3.2 导航 **[P1]**

- [ ] 主导航至少覆盖默认 UI 的页面集合：**本地**（`/`）、**社区**（`/hub`）、
  **下载**（`/downloads`）、**设置**（`/settings`，含常规/壁纸/外观三个子页）、**关于**（`/about`）。
- [ ] 保持 `navigate` 事件可达：收到 `{path}` 跳对应路由，`{target}` 跳 `/hub?target=…`。
  托盘菜单与深链二次启动依赖此协议——皮肤自定路由时必须提供等价映射。
- [ ] 下载导航项带**进行中任务数角标**（>99 显示 `99+`），数据源见 §5。
- [ ] 壁纸库空白处右键菜单：创建壁纸 / 创建播放列表。

### 3.3 全局事件响应 **[P0/P1]**

| 事件 | 级别 | 皮肤应做的响应 |
|---|---|---|
| `playing-status-changed` | **P0** | 载荷为空 → 主动 `api.getPlayingStatus()` 重拉并刷新播放相关 UI |
| `download-status-changed` | P1 | 更新下载角标与下载页；载荷为**增量推送**，需按 `id` 合并去重 |
| `navigate` | P1 | 按上表路由跳转（托盘 / 深链入口） |
| `appearance-changed` | P1 | 重读 Appearance 配置应用主题变化 |
| `system-theme-changed` | P1 | 自身 mode 为 `system` 时切换明暗配色（载荷 `{mode}`） |
| `skins-changed` | P1 | 有皮肤管理界面时刷新 `listSkins()` 列表 |
| `mpv-download-event` | P1 | 展示 mpv 下载进度 / 完成刷新状态 / 失败提示（取消不报错） |
| `hub-session-changed` | P1 | 重载社区页以反映登录态变化 |
| `refresh-page` | P0 | SDK 内置自动 reload，不要阻断；设 `WallpaperClientConfig.skipAutoRefresh` 接管后，`reason: "wallpaper-config"` 软刷新、其余来源仍 reload |

### 3.4 主题与多语言 **[P1]**

- [ ] 读取并应用 `Appearance.mode`（`system` / `light` / `dark`），system 跟随系统切换。
- [ ] `Appearance.theme` 是默认皮肤的 12 色板（zinc/slate/stone/gray/neutral/red/rose/orange/
  green/blue/yellow/violet）；app 型皮肤可自行决定是否响应（至少不因该值异常崩溃）。
- [ ] 多语言：读 `General.currentLan`（`zh`/`en`/`ru`/`es`，缺省 `en`）加载对应文案；
  **语言在启动时加载，切换后需整页 reload 才生效**。皮肤可自带词典，但建议覆盖这 4 种语言。
- [ ] 启动引导：读配置 → 应用语言/主题 → 注册事件 → 最后 `shell.hideLoading()`；
  就绪前可渲染空 / 启动占位，避免闪烁（默认 UI 延迟约 300ms 再拉列表防闪屏）。

### 3.5 反馈与状态 **[P1]**

- [ ] 统一 toast 反馈：成功 / 失败均有提示；错误消息截断展示（默认 UI 截 120 字符）。
- [ ] 破坏性操作前确认框（原生 `confirm` 或自绘 AlertDialog 均可）：
  删除壁纸、清空下载历史、未保存关闭对话框。
- [ ] 列表类页面三态：加载骨架 / 空态（含引导动作）/ 错误 toast。

## 4. 本地壁纸库页

实现：`src/giantapp-wallpaper-ui/src/pages/home/`。

### 4.1 壁纸网格 **[P0]**

- [ ] 拉取 `api.getWallpapers()` 展示全部壁纸；`fileUrl` 为空的条目跳过渲染。
- [ ] 卡片要素：封面（`coverUrl` → `fileUrl` → 内置 placeholder 兜底；刷新时 coverUrl 追加
  `?t=时间戳` 防缓存）+ 类型图标 + 标题。
- [ ] **点击卡片 = 应用到全部屏幕**：`wallpaper.runningInfo.screenIndexes = []` 后
  `api.showWallpaper(w)`；成功后刷新播放状态。
- [ ] 多屏时悬停显示**逐屏应用按钮**（每屏一个），按 `deviceName` 匹配屏幕索引后
  `showWallpaper`；文案含屏幕名（词典 `apply_screen_effect` 的 `{0}` 占位）。
- [ ] 悬停操作按钮：**设置**（打开单壁纸设置）、**编辑**、**删除**（确认框 →
  `api.deleteWallpaper` → 失败 toast）、**打开文件位置**（`api.explore(filePath)`）。
- [ ] 网格末尾"创建"入口（创建壁纸 / 创建播放列表）；列表为空时隐藏创建卡片、
  显示空态（标题 + 说明 + [创建壁纸] [修改文件夹→壁纸设置] 两个动作）。
- [ ] 加载骨架屏；拖文件进窗口 = 打开创建对话框（快速导入）。
- [ ] 状态刷新来源：操作后主动 `getPlayingStatus()` + 订阅 `playing-status-changed`。

### 4.2 创建 / 编辑壁纸与播放列表 **[P1]**

实现：`pages/home/_components/wallpaper-dialog/`。对话框同时承担创建与编辑
（以 `meta.id` 区分），标题/描述随"壁纸×列表 × 创建×编辑"四态切换。

- [ ] 字段：标题（必填校验，空则取文件名 / `unnamed_list`）、类型选择
  （自动检测 / 图片 / 动图 / 视频 / Web / 播放列表；**exe 类型不开放**）。
- [ ] 文件导入：点击选择或拖入 → **分块 base64 上传**（`api.uploadToTmp`，约 50KB/块
  覆盖写，带进度条与中止）→ 预览（video 自动循环播放，加载失败有提示）→ 可删除重选。
- [ ] 文件大小两道阈值：选择时 >500MB 拒绝；提交时 >1GB 拒绝（均有 toast 提示）。
- [ ] **封面自动生成**：从预览元素 canvas 截帧（宽 500 等比 JPEG）→ `uploadToTmp`；
  失败 toast 但继续提交（允许空封面）。
- [ ] **播放列表模式**：成员选择器（§4.2.1）；成员为空不允许提交；
  封面为成员封面 **3x3 网格拼接**（最多 9 张，`crossOrigin='Anonymous'`，失败走默认封面）；
  成员卡片可单独移除。
- [ ] 提交分流：无 `meta.id` → `api.createWallpaperNew(w)`；有 id →
  `api.updateWallpaperNew(w, oldFileUrl)`。成败均有 toast；成功后列表局部更新
  （编辑）或整表刷新（创建）。
- [ ] 关闭对话框：内容有改动时先确认（`not_saved_confirm_close`）；关闭时中止进行中的导入。

#### 4.2.1 播放列表成员选择器 **[P1]**

- [ ] 大对话框列出壁纸库（复用网格卡片样式，选中态描边），底部**全选** Checkbox + 确认按钮。
- [ ] **过滤掉播放列表类型**（不允许嵌套）；Enter 键可快捷保存。
- [ ] 追加模式合并成员（不去重）；排除自身。

### 4.3 单壁纸设置对话框 **[P1]**

实现：`pages/home/_components/setting-dialog.tsx`。按 `meta.type` 条件渲染，
保存走 `api.setWallpaperSetting(setting, wallpaper)`（保存即热应用）。

| 字段 | 适用类型 | 控件 | 默认值 |
|---|---|---|---|
| `duration` 播放时长 | 除播放列表外全部 | 时间输入 `hh:mm`（列表项在本列表的停留时长） | — |
| `playMode` 播放模式 | 播放列表 | 下拉：顺序 / 随机（枚举另含 Timer 定时，UI 未开放） | Order |
| `enableMouseEvent` 鼠标交互 | Exe / Web | 开关 | true |
| `videoPlayer` 视频播放器 | 视频 | 下拉：默认 / MPV / 系统 | Default |
| `hardwareDecoding` 硬解 | 视频 | 开关（说明文案：降低 CPU 占用） | true |
| `isPanScan` 铺满拉伸 | 视频 | 开关 | true |
| `fit` 契合度 | 图片 | 下拉：居中/平铺/拉伸/适应/填充/跨屏（Fit 枚举 0-5） | Fill(4) |
| `keepWallpaper` 保留壁纸 | 图片 | 开关 | true |

- [ ] 保存中禁用按钮 + spinner；表单有改动时关闭需确认。

### 4.4 播放控制条 **[P0]**

实现：`pages/home/_components/tool-bar/`。底部固定条，展示正在播放的壁纸并提供控制。
多屏核心约定：**`screenIndex = -1 表示全部屏幕`**，单屏控制取
`runningInfo.screenIndexes[0]`。

- [ ] 左区：正在播放壁纸封面（`coverUrl` + 时间戳）+ 标题 + 描述；多个播放项时
  可**点击封面选中**某一项作为控制目标（再次点击取消），选中态旁有"返回列表"按钮。
- [ ] 中区控制按钮：**上一条 / 下一条**（仅目标是播放列表时显示，`playPrev/NextInPlaylist`）、
  **停止**（`stopWallpaper(screenIndex)`，本地同步移除该项）、**暂停/恢复**
  （`pauseWallpaper` / `resumeWallpaper`，按 `runningInfo.isPaused` 切换）。
- [ ] 可暂停判定：类型为 Video / Playlist（或未知类型）才显示暂停组；图片不可暂停。
- [ ] **进度条**（仅 Video / Playlist 显示）：每秒轮询 `api.getWallpaperTime(screenIndex)`；
  `position/duration == -1` 视为无效不更新（图片壁纸即 -1）；拖动立即更新本地值，
  300ms debounce 后 `api.setProgress`；**设置进度后 2 秒内不回读**（防回跳）；
  窗口隐藏（`document.shell_hidden`）或暂停中停止轮询；时间格式化支持天/时
  （`3d` / `02:05:30` / `mm:ss`）。
- [ ] **音量**：0–100 滑杆，300ms debounce 后 `api.setVolume(v, screenIndex)`；
  图标随音量分档（0 / ≤50 / >50）。
- [ ] **音源选择**（未选中具体屏时显示，多屏场景）：弹层列出各屏
  （`{0}` 占位替换 deviceName）+「静音」项；选择即把该屏设为音源
  （`setVolume(100, index)`），静音 = `setVolume(0, -1)`；回显当前 `audioScreenIndex`。
- [ ] 自动选中逻辑：仅一个播放项时自动选中；多屏时选中跟随已选屏幕上仍存在的壁纸。

## 5. 下载管理页 **[P1]**

实现：`src/giantapp-wallpaper-ui/src/pages/downloads.tsx`。

- [ ] **进行中区**：`api.getDownloadStatus()` 播种 + 订阅 `download-status-changed`
  （**增量推送，必须按 `id` 合并**；`!isDownloading || IsCanceled` 的任务移除；
  任务结束自动刷新历史）。每条：任务名（`desc` 缺省显示 id）、百分比、进度条、
  已收/总字节（B→TB 自适应单位）、**取消**按钮（`api.cancelDownloadWallpaper(id)`）。
  空态：虚线框提示。
- [ ] **历史记录区**：`api.getDownloadHistory()`；每条：封面（placeholder 兜底）、
  标题、文件大小、完成时间（`completedAt` 毫秒时间戳 → `toLocaleString`）、
  **打开文件夹**（`api.explore(filePath)`）、**删除单条**（`api.removeDownloadHistoryItem(id)`）。
  空态提示。
- [ ] **清空历史**：确认框（文案说明"只删记录不删壁纸文件"）→ `api.clearDownloadHistory()`，
  失败 toast。
- [ ] 同一数据源驱动 §3.2 的导航角标。

## 6. 社区 Hub 页 **[P1]**

实现：`src/giantapp-wallpaper-ui/src/pages/hub.tsx`。

默认实现用**后端托管的独立 WebView**（社区站是第三方站，iframe 会导致登录态
Cookie 不同步）。皮肤可选实现方式，但需提供等价能力：

- [ ] 展示社区站（默认 `https://wallpaper.giantapp.cn`，可用构建变量 `VITE_HUB_ADDRESS` 覆盖）。
  URL 规则：query `?target=...` 优先（深链），否则
  `` `${HUB_ADDRESS}/${lang}/explorer?mode=${themeMode}` ``（mode 取当前明暗模式）。
- [ ] 若用独立 WebView 协议：容器元素上报矩形——`ResizeObserver` + window resize
  （rAF 节流）→ `api.setCommunityWebview({visible, x, y, width, height})`；
  切走 / 卸载时 `setCommunityWebview({visible:false, 1×1})` 仅隐藏不销毁，保留页面状态。
- [ ] **登录**（GitHub OAuth 等授权页拒绝 iframe 嵌套）：走
  `api.openCommunityWindow(url)` 在独立顶层窗口完成；会话变化经 `hub-session-changed`
  通知 → 重载社区页。
- [ ] 辅助动作：重载社区页（破缓存）、系统浏览器打开（`api.openUrl`）。

## 7. 设置页

实现：`src/giantapp-wallpaper-ui/src/pages/settings/`。布局：左侧分类导航
（常规 / 壁纸 / 外观）+ 右侧内容区。

> ⚠️ **配置契约**：`setConfig` 是**整组替换**（缺字段按后端默认值落盘）。
> 任何保存都必须"读全组 → merge → 整组写回"，绝不只写单字段。

### 7.1 常规 **[P1]**（配置组 `General`）

实现：`pages/settings/general.tsx`。

## 9. 易漏细节清单（最高频踩坑点）

做新皮肤时最容易漏的业务规则，逐条核对：

1. **`screenIndex = -1` 表示全部屏幕**；单屏控制取 `screenIndexes[0]`。
2. `playing-status-changed` **载荷为空**，必须重拉 `getPlayingStatus()`；
   默认 UI 主页反而是操作后主动拉取——两种模式都行，但要保证最终一致。
3. **播放中判定要展开播放列表成员**：当前项可能是 `meta.wallpapers[playIndex]`
   （SDK 提供 `findPlayingWallpaper` / `isSame` 工具）。
4. **播放列表不能嵌套播放列表**（选择器必须过滤）。
5. `setConfig` **整组替换**——只写单字段会把其余字段重置为默认值。
6. 下载事件是**增量推送**，必须按 `id` 合并，不能整表覆盖。
7. 进度条三条防抖规则：拖动 300ms debounce、**设置后 2 秒不回读**、
   窗口隐藏 / 暂停时不轮询；`-1` 值无效。
8. 封面刷新要加 `?t=时间戳` 防缓存（媒体协议内容会变，URL 不变）。
9. 语言切换保存后必须 **reload**（语言在启动时加载）。
10. 保存 `Wallpaper` 配置组后后端广播 `refresh-page` 整页刷新——皮肤不要与之对抗；
    需要页面刷新语义的动作（如语言、引擎切换）可直接 `location.reload()`。
11. 标题栏 **关闭按钮 = 隐藏到托盘**，不是退出；退出是 `exitApp`。
12. 拖文件入窗 = 打开创建对话框；导入大文件必须**分块** base64（整文件 btoa 会栈溢出）。
13. `fileUrl` 为空的库条目直接跳过渲染；封面/文件一律走 `media.localhost` URL。
14. 确认框语义：删除壁纸、清空下载历史、未保存关闭，三处必确认。

`src-tauri/src/generated/client-sdk.js`（`bun run build:sdk` 重新生成）。

| 方法 | 说明 |
|---|---|
| `getConfig(key)` / `setConfig(key, value)` | key ∈ `"General" \| "Wallpaper" \| "Appearance"`；set 为整组替换 |

### api — 壁纸库

| 方法 | 说明 |
|---|---|
| `getWallpapers()` | 媒体库全量（fileUrl / coverUrl 已填充） |

### api — 播放控制

| 方法 | 说明 |
|---|---|

## 12. 配置项速查表

默认值以后端 `src-tauri/crates/wallpaper-core/src/config.rs` 为准；**setConfig 整组替换**。

### `General`

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `autoStart` | bool | false | 开机启动（后端维护注册表） |
| `hideWindow` | bool | false | 启动时隐藏主窗口 |
| `autoStartHeadless` | bool | false | 开机自启时无窗口运行 |
| `currentLan` | string | 系统语言（归一化为 zh/en/ru/es，非法→en） | 语言，改后需 reload |

### `Appearance`

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `theme` | string | `"zinc"` | 主题色板 id（12 选 1） |
| `mode` | `"system"\|"light"\|"dark"` | 前端即时渲染 `system`；后端落盘 `dark` | 明暗模式 |
| `skin` | string | `"default"` | 生效皮肤 id |

### `Wallpaper`

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `directories` | string[] | `[]`（运行期空值回退默认目录） | 媒体库目录 |
| `coveredBehavior` | 0\|1\|2 | 1（暂停） | 遮挡行为：继续 / 暂停 / 停止 |
| `defaultVideoPlayer` | 0\|1\|2 | 1（MPV） | 0 Default / 1 MPV / 2 系统(内嵌 WebView) |
| `keepWallpaper` | bool | false | 退出时保留壁纸（TS 类型暂缺此字段，后端存在） |

### 关键只读数据结构

- `Wallpaper { dir, fileName, fileUrl, filePath, coverUrl, coverPath, meta, setting, runningInfo }`
- `WallpaperMeta { id, title, description, type, playIndex, wallpapers[] }`
- `WallpaperSetting`：见 §4.3 表格；`defaultSetting()` =
  `{enableMouseEvent:true, hardwareDecoding:true, isPanScan:true, videoPlayer:0, playMode:0, fit:4, keepWallpaper:true}`
- `WallpaperType`：0 NotSupported / 1 Img / 2 AnimatedImg / 3 Video / 4 Web / 5 Exe / 6 Playlist
- `PlayingStatus` / `Screen` / `ScreenCoverage` / `DownloadItem` / `DownloadHistoryItem` /
  `SkinInfo`：字段见 SDK `types`（`DownloadItem.IsCanceled` 为兼容 v3 的大写字段）。

## 13. style 型皮肤需求

style 型皮肤不替换界面，只注入一份 CSS，需求集中在 **token 覆盖**：

- [ ] 默认皮肤的可覆盖面是三层 CSS 变量体系：`globals.css` 的 shadcn 全套变量

  destructive / border / input / ring / `--radius`）→ `.dark` 明暗覆盖 → `.theme-*` 色板类。

  改标题栏高度时必须同步该变量。
- [ ] 明暗两套都要给（`.dark` 前缀选择器），否则另一种模式下样式缺失。
