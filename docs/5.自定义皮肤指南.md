# 自定义皮肤开发指南（可直接复制给 AI）

> 本文档面向想自定义界面的用户：把全文复制给任意 AI（ChatGPT / Claude 等），
> 让它按下面的规范为你生成一套皮肤，再把产出的文件放进皮肤目录即可使用。
> 应用内：设置 → 外观 → 皮肤 → 「自定义皮肤」可随时打开本文。

---

## 给 AI 的任务说明

请你作为资深前端工程师，为 Windows 动态壁纸软件「巨应壁纸 IV」生成一个
**完整可用的皮肤**：任意技术栈的纯静态前端（推荐零构建的原生
HTML/CSS/JS，便于用户直接保存使用），整体替换应用主界面。

要求：**交付一个完整的文件树**——每个文件给出完整内容（不要省略、不要
“此处省略”），并标注每个文件应保存的相对路径。用户会把文件放进
`skins/<皮肤id>/` 目录下直接使用。

## 硬性契约（不满足会白屏 / 404）

1. **目录结构**：皮肤 = 一个文件夹，放在应用皮肤目录
   （设置 → 皮肤 → 打开皮肤目录 可见，通常是
   `%LOCALAPPDATA%/LiveWallpaper4/skins/`）下：

   ```
   skins/
   └─ my-skin/
      ├─ skin.json        # 清单（必需）
      ├─ index.html       # 入口（app 型）
      └─ ...任意静态资源（js/css/图片/字体…）
   ```

2. **`skin.json` 清单**（字段必须齐全）：

   ```json
   {
     "id": "my-skin",
     "name": "我的皮肤",
     "version": "1.0.0",
     "author": "you",
     "description": "一句话描述",
     "type": "app",
     "entry": "index.html",
     "compat": 4
   }
   ```

   - `id`：仅字母数字与 `-_.`，不得以 `.` 开头，且不能为 `default`；
   - `type`：`app` = 完整替换界面；`style` = 仅注入一份 CSS 覆盖现有皮肤
     （此时 `entry` 是 CSS 文件）；
   - `compat` 必须为 `4`。

3. **资源引用必须用页面相对路径**：`src="app.js"`、`href="style.css"`，
   **不要带前导 `/`**（皮肤页面位于 `http://skin.localhost/<id>/index.html`，
   根相对路径会丢掉 `<id>` 段而 404）。唯一例外是 SDK：
   `<script src="/_sdk/client.js"></script>` 必须带前导 `/`。

4. **引入 SDK**（`<head>` 内）：`<script src="/_sdk/client.js"></script>`，
   之后获得全局 `window.WallpaperClient`。

5. **启动收尾**：页面加载完成后必须调用一次
   `window.WallpaperClient.shell.hideLoading()`（幂等）——它关闭启动屏并
   显示主窗口。漏调时后端有约 5 秒兜底，但正常路径必须自己调。

6. **媒体地址**：壁纸封面 / 视频文件直接使用 API 返回的 `fileUrl` /
   `coverUrl` 字段（形如 `http://media.localhost/...`），不要自己拼本地路径。

7. **不要拦截 `refresh-page` 事件**：SDK 已内置订阅并整页刷新（皮肤文件
   热更新依赖它）。确需接管（如按 `payload.reason` 做软刷新）时，在引入
   SDK **之前**设
   `window.WallpaperClientConfig = { skipAutoRefresh: true }`，并自行
   `on("refresh-page", ...)`；其余来源仍应整页 reload。

## 客户端契约（SDK）

```js
const { api, shell, types, on } = window.WallpaperClient;
const res = await api.getWallpapers();   // ApiResult<T>: { error, data }
await api.showWallpaper(res.data[0]);    // 应用壁纸
on("playing-status-changed", () => refresh());
```

- 所有 `api.*` 返回 `ApiResult<T>`：`{ error, data }`，先判 `error`。
- **配置是整组读写**：`getConfig("Appearance")` 取整组、
  `setConfig("Appearance", 完整对象)` 写整组——写回前必须 merge 你拿到的
  完整对象，只传单个字段会把其余字段清掉。

### 常用命令（api 方法 ↔ 后端 command）

| 功能 | 调用 |
|---|---|
| 壁纸库 | `getWallpapers()` / `showWallpaper(w)` / `deleteWallpaper(w)` |
| 播放控制 | `pauseWallpaper(screen?)` / `resumeWallpaper(screen?)` / `stopWallpaper()` / `playNextInPlaylist()` / `playPrevInPlaylist()` |
| 播放状态 | `getPlayingStatus()`（含每屏壁纸、进度、音量、播放列表）/ `getWallpaperTime(screen)` / `setProgress(sec, screen)` / `setVolume(v, screen?)` / `getScreenCoverage()` |
| 配置 | `getConfig("General"\|"Wallpaper"\|"Appearance")` / `setConfig(key, value)` |
| 下载 | `downloadWallpaper(item)` / `getDownloadStatus()` / `getDownloadHistory()` / `cancelDownloadWallpaper(id)` |
| 皮肤 | `listSkins()` / `setActiveSkin(id)` / `openSkinsFolder()` |
| 系统 | `getVersion()` / `openUrl(url)` / `explore(path)` / `getMpvStatus()` |

### 事件（`on(name, callback)`）

| 事件 | 处理建议 |
|---|---|
| `playing-status-changed` | **P0**：载荷为空时主动 `getPlayingStatus()` 重拉，刷新播放 UI |
| `download-status-changed` | 刷新下载列表 / 进度 |
| `appearance-changed` | 主题配置变化时刷新 |
| `refresh-page` | SDK 内置整页 reload，不要阻断 |
| `navigate` | `payload.target` 为深链目标（如社区页） |
| `skins-changed` | 皮肤目录变化，设置页刷新皮肤列表 |
| `hub-session-changed` | 社区登录态变化 |

## 功能需求（完整皮肤应覆盖）

**P0（不做等于不可用）**：硬性契约全部满足；壁纸库浏览（封面网格、
悬停预览）、应用 / 停用壁纸、播放控制条（暂停 / 继续 / 上一个 / 下一个 /
进度 / 音量）、播放状态实时刷新。

**P1（构成完整体验）**：本地库管理（文件夹、创建视频 / 网页 / 播放列表
壁纸、编辑与删除）、下载管理页（从社区下载记录、进度、清空）、设置页
（常规：开机启动 / 语言；壁纸：目录管理 / 遮挡行为 / 默认视频引擎 /
保留壁纸；外观：模式 / 主题色 / 皮肤切换）、关于页（版本 / 反馈入口 /
退出）、自绘标题栏（无边框窗口：最小化 / 最大化 / 关闭到托盘）、
社区 Hub 页嵌入。

**P2（可选）**：评分弹窗、快捷键、动效增强等。

> 注意：窗口由后端托管（无边框），皮肤页面自绘标题栏；关闭按钮调
> `closeWindow()`（隐藏到托盘，不是退出应用）。

## 开发与调试

- **热更新**：改皮肤文件保存后主窗口约半秒自动刷新（后端监听皮肤目录），
  与普通前端开发体验一致。
- **浏览器直开演示模式**：直接双击 `index.html`（检测不到应用环境）时
  建议进入演示模式（mock 数据渲染完整界面），便于设计走查。判断方式：
  `window.WallpaperClient` 不存在即演示模式。
- **清单非法 / 入口缺失**：设置页会标记该皮肤不可用；已应用的皮肤失效时
  主窗口自动回退，永不白屏。

## 最小骨架（可直接作为起点）

```html
<!DOCTYPE html>
<html lang="zh">
<head>
  <meta charset="UTF-8" />
  <title>我的皮肤</title>
  <link rel="stylesheet" href="style.css" />
  <script src="/_sdk/client.js"></script>
</head>
<body>
  <h1>我的皮肤</h1>
  <div id="list"></div>
  <script src="app.js"></script>
</body>
</html>
```

```js
// app.js
const { api, shell, on } = window.WallpaperClient;

async function main() {
  const res = await api.getWallpapers();
  const list = document.getElementById("list");
  for (const w of res.data || []) {
    const card = document.createElement("div");
    card.textContent = w.name || w.id;
    card.onclick = () => api.showWallpaper(w);
    list.append(card);
  }
  await api.showWallpaper((res.data || [])[0]);
  shell.hideLoading(); // 必须：关闭启动屏、显示主窗口（幂等）
}
main();
on("playing-status-changed", () => location.reload()); // 简化示例；正式皮肤建议重拉状态局部刷新
```
